Accessibility advocacy

Building for everyone

Accessibility is not an optional extra to me. As a blind developer, I’m a major accessibility advocate, and I care about making technology usable, understandable, and welcoming for people with different disabilities and ways of navigating.

I advocate for semantic HTML, visible focus, keyboard support, high contrast, readable structure, screen-reader navigation, and interfaces that do not hide important information behind unnecessary interaction.

Looscid

Accessible local-first web workspace

Looscid is an accessible, local-first, decentralized web operating environment and workspace. It is a focused framework and evolving project, not a claim to replace iOS or Android today.

Its purpose is to give people more control over their data, identity, and daily tools through digital sovereignty: work should remain useful on the local device, while synchronization and collaboration can be decentralized rather than controlled by one platform.

Accessibility is part of the architecture. The interface uses semantic landmarks, predictable heading structure, keyboard and screen-reader navigation, discrete content blocks, and aria-live status messaging so important state changes can be announced without forcing users through visually dependent interactions.

RU a cheater

RU a cheater is a joke project built around a simple input-to-result interaction. It demonstrates how a small client-side experience can be readable, keyboard-friendly, and usable without collecting personal data.

Persona evaluator

Persona evaluator is a playful evaluation experiment. Its value is in making a structured result understandable: clear labels, predictable output, and a simple flow that does not hide the result behind unnecessary UI.

Visit it on GitHub

Reactor toolbar

Reactor toolbar explores a reaction interface with gestures and rich reactions while keeping the interaction model explicit. The design challenge is to provide fast feedback without making gestures the only path, so controls and state can remain discoverable to keyboard and screen-reader users.

Visit Reactor toolbar on GitHub

Easyconvert

Easyconvert is a local utility for working with JSON and ZIP data archives. Its parsing and conversion workflow is designed to work offline, keeping files on the user’s device instead of requiring an upload to a remote service. That makes the tool practical for privacy-sensitive data and unreliable connections.

Visit Easyconvert on GitHub

Alex Classic

Alex Classic is an audio and voice project focused on extracting and working with wavetable data. It reflects the same interest in making technical systems inspectable and useful to blind developers: the important processing steps should be understandable through accessible output rather than hidden behind a visual-only tool.
