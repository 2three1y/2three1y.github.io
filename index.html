Accessibility advocacy

Building for everyone

Accessibility is not an optional extra to me. I care about semantic HTML, visible focus, keyboard support, high contrast, readable structure, screen-reader navigation, and interfaces that do not hide important information behind unnecessary interaction.

Looscid

An autonomous local-first workspace

Looscid is an autonomous, local-first decentralized web workspace built around digital sovereignty. It is an evolving operating environment for keeping data and daily tools useful on the local device, rather than presenting itself as a finished replacement for iOS or Android.

The technical focus is screen-reader ergonomics: predictable landmarks and headings, short discrete blocks, keyboard-first movement, and status changes exposed through aria-live messaging. The goal is a workspace that feels calm and navigable when every interaction is being spoken.

Projects

Memeprojects

Memeprojects is a set of lightweight, zero-dependency browser toys. Each one is a small proof that accessible interactive fun can load instantly, stay understandable to a screen reader, and work without trackers or an account system.

Explore Memeprojects on GitHub

RU a cheater

RU a cheater turns a simple input and result into a deliberately silly no-tracking experience. Its technical value is restraint: client-side behavior, readable output, and no unnecessary service layer.

See the source on GitHub

Persona evaluator

Persona evaluator experiments with structured prompts and clear result presentation. The interface keeps labels and outcomes explicit so the experience remains usable without relying on visual cards, hidden controls, or unexplained animation.

Visit it on GitHub

Reactor Toolbar

Reactor Toolbar is a rapid keyboard-first development harness for reaction interfaces. Structured prompt engineering drives quick experiments, while explicit controls and announced state keep the resulting interaction discoverable to keyboard and screen-reader users.

Visit Reactor Toolbar on GitHub

Easyconvert

Easyconvert is built for instant offline conversion of JSON and ZIP archives: choose a file, parse it locally, and get the converted result without uploading anything to the cloud. Privacy-hardened file sanitization is part of the workflow, making it safer for sensitive archives and useful when connectivity is unreliable.

Visit Easyconvert on GitHub

Alex Classic

Alex Classic is a retro speech preservation project. It investigates extracting the 670 MB of wavetables from OS X 10.5 Leopard’s Alex.SpeechVoice, then carrying that character into an offline synthesis pipeline to counter modern iOS speech degradation and pitch distortion.

Visit Alex Classic on GitHub
