Braille Text Field Label Occlusion Reproduction

Case-ID: 22245181

This is an isolated minimal test case built specifically for Apple Accessibility engineering to reproduce the text field indicator truncation on 20-cell Braille displays. It does not reference any third-party production site. We apologize for using a minimal reproduction demo rather than a commercial third-party site; this page is intentionally stripped down so that only the behavior under test is present.

Reproduction steps

  1. Connect a 20-cell Braille display via Bluetooth.
  2. Navigate with Rotor or Pan keys to the long text fields.
  3. Observe the editability indicator behavior and label occlusion.
