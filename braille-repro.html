Braille Text Field Label Testing Playground

This is a minimal, neutral page for testing how text field labels and editability indicators display on 20-cell Braille displays. All field labels and values are generic sample text.

Testing steps

  1. Connect a 20-cell Braille display via Bluetooth.
  2. Navigate with Rotor or Pan keys to the text fields below.
  3. Observe the editability indicator behavior and how the label displays.
